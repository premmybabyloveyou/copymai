# IP Trace frontend prototype

React + Vite + TypeScript + Tailwind CSS v4. Frontend only; all data/actions are mock examples and no credentials are saved.

## Run
1. Open this folder in VS Code.
2. Run `npm install` in the integrated terminal.
3. Run `npm run dev` and open `http://localhost:3000/`.

## Structure
- `src/pages`: Login, Register, Dashboard, Scan, Results, Reports, Community Report and Plans.
- `src/components`: shared UI pieces.
- `src/layouts`: shared app shell.
- `src/data`: mock data.
- `src/styles`: Tailwind import and visual styles.
- `src/types`: shared TypeScript types.
